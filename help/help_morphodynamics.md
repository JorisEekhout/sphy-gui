# Channel morphodynamics module

Channel morphodynamics can be simulated when the travel time routing algorithm is used in combination with the erosion and sediment transport modules. The grain size distribution needs to be provided as percentages for clay, silt, sand and gravel. The channel morphodynamics can be calibrated using two model parameters which indicate the relative thickness of the moveable layer in the rills and the channels, respectively.

See Eekhout et al. (2024) for more details on the implementation and a case study.
