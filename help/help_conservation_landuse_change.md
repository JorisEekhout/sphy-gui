# Land use change

Land use change can be simulated by providing a map which indicates where the land use change and to which existing land use class, as defined in the original land use map in the General tab. So if afforestation is being simulated, where shrubland (class 1) is replaced by forest (class 2), then the land use change map should have a value of 2 in all the area where the original land use map has a value of 1. All other values can either be 0 or missing value. Using this map, the model will update the original land use map and assign the land use specific values to the new land use map (e.g. the values defined in the tables of the Vegetation and Erosion tabs). Moreover, when the Vegetation module is used, the NDVI values of the changed land use areas will be changed. As for the example of afforestation. The average NDVI of forest of the original land use map will be projected to the new forest area.
