# SPHY Model Graphical User Interface (SPHY GUI)

[![Latest Release](https://img.shields.io/github/v/release/JorisEekhout/sphy-gui?color=blue&label=latest%20release)](https://github.com/JorisEekhout/sphy-gui/releases/latest)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://gnu.org/licenses/gpl-3.0)

A standalone PyQt-based Graphical User Interface for configuring, running, and analyzing the **SPHY (Spatial Processes in HYdrology)** model.

---

## Downloads & Installation

Visit the [**Latest GitHub Release**](https://github.com/JorisEekhout/sphy-gui/releases/latest) to download the installer:

| Installer Package | Target Audience | File |
| :--- | :--- | :--- |
| **Full Installer** | First-time setup / standalone install | `SPHY_Setup_v1.0.exe` |
| **Update Patch** | Upgrading an existing SPHY installation | `SPHY_Update_v1.0.exe` |
| **Source Archive** | Standalone Python environment | `src_archive_v1.0.zip` |

### Option A: Standard Windows Installation
1. Download **`SPHY_Setup_v1.0.exe`**.
2. Run the installer and follow the setup wizard (installs the GUI at `C:\SPHY_Model`).
3. Launch the application from your Desktop shortcut.

### Option B: Upgrading Existing Installations
If you already have SPHY installed at `C:\SPHY_Model`, download and run **`SPHY_Update_v1.0.exe`** to apply code updates without re-downloading environment binaries.
